# Mukai Engineering & Infrastructure Platform

> **Modern digital platform for engineering, construction, and infrastructure management.**  
> Built with Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

🚀 **Live Deployment:** [mukaiburger.vercel.app](https://mukaiburger.vercel.app)

---

## 🏗️ Overview

This platform serves as the digital front for an engineering and infrastructure firm (Est. 2018, RC: 1300720). The site communicates institutional reliability, precision engineering, and structured execution across industrial, commercial, civil, and residential projects.

The architecture emphasizes fluid scroll-driven interaction, modern component composition, and optimized Core Web Vitals across all device viewports.

---

## ✨ Features & Architecture

- **Scroll-Driven Motion**: Parallax hero headers, sticky trust metrics, and scroll-linked progress reveals powered by `framer-motion`.
- **Modern Next.js 15 Architecture**: App Router with React 19 Server Components for fast initial server rendering and client-side interactive islands.
- **Tailwind CSS v4 & Precision Design System**: Clean typography, corporate blueprint aesthetic, responsive clamp-based scaling, and dark-mode ink palette.
- **Sector & Portfolio Showcase**: Dynamic sector filtering (Industrial, Commercial, Institutional, Civil, Residential) and project breakdowns.
- **Interactive Decision Flow**: Smooth scroll navigation, back-to-top telemetry, and modal quote request integration.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/davidalbertstark-lab/mukaiburger.git
cd mukaiburger

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Building for Production

```bash
npm run build
npm run start
```
